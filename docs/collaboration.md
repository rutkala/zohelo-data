# Working on Zohelo-data

This repository covers zohelo-data and data.zohelo.com, not other zohelo projects.
[AGENTS.md](../AGENTS.md) is the common guide for every coding tool. The latest
explicit owner task takes precedence over historical priorities and work queues.

Use one implementation owner, a focused change and a clear result. Do not
implicitly delegate, spawn agents, resume an old programme or schedule follow-up
work. Existing authorized schedules are not cancelled merely by editing a guide.
Check their real state when the task needs it; do not claim continuous work.

Read only the files relevant to the current task. Prefer direct Python/SQL and
existing commands over new frameworks, workflows, reports or acceptance machinery.
Keep source intake, downstream modeling and optional diagnostics distinct. A
routine operation must not run broad regressions merely because old instructions
said they were always required. Validate changed behavior with relevant checks.

Current status belongs in [deliverables.md](deliverables.md), technical boundaries
in [architecture.md](architecture.md), and operating commands in the
[workflow inventory](audits/2026-09-07-workflows.md). Do not copy project tracking
into the portal. Historical records remain evidence, not an active task list.

Preserve other contributors' work, secrets, production writer ownership and
retained data. R2/Iceberg remains the agreed target; a repository cleanup is not a
producer/reader cutover. Distinguish code merged, portal deployed, data verified,
and work still pending. Report the actual command/check result, not an invented
success or unmeasured token saving.

## Cost boundaries

No new paid services, API-key/Cloud/Vertex model billing, credits or overages
without explicit owner approval. Existing subscription access is not permission
to launch another agent. When explicitly using personal Gemini/AGY access, keep
AI Credit Overages at Never (`useG1Credits: false`); Drive OAuth is separate.
Respect the existing compute/storage allowances and stop rather than silently
switching to a billed model-access route.

The former default delegation ladder, autonomous source-onboarding directions
and long restart checklist are historical. The owner's current priority is
simplification of existing capabilities, not expansion.
